# Portfólio — Vitor Ferreira

Currículo e portfólio acadêmico/profissional desenvolvido com Next.js, React, Zustand, TanStack Query e Axios.

## Tecnologias
- Next.js (App Router)
- Zustand (dark/light mode)
- TanStack Query + Axios (data fetching)
- GitHub API (listagem de repositórios)

## Páginas
- `/` — Home
- `/sobre` — Sobre mim e tecnologias usadas
- `/academica` — Experiência Acadêmica
- `/profissional` — Experiência Profissional
- `/projetos` — Projetos Desenvolvidos
